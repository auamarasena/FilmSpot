# FilmSpot
Install Node Package Manager in both frontend and backend . Then Install Node Package Manager in root directory called FilmSpot.
Example :

FilmSpot/ npm install

FilmSpot/cd backend
FilmSpot/backend
npm install

FilmSpot/backend/cd../
FilmSpot/cd frontend
FilmSpot/frontend
npm install

then run both backend and frontend using npm run dev
